# Contributing to Saudi Law Tools

Thank you for your interest in contributing to Saudi Law Tools.

Saudi Law Tools is an open-source project for parsing, normalizing, and structuring Saudi Arabian legal and regulatory text. Contributions of all sizes are welcome.

## Ways to Contribute

You can contribute by:

- Reporting parsing errors
- Adding examples from real-world Saudi legal document structures
- Improving Arabic text normalization
- Adding support for additional article, chapter, or section formats
- Writing tests
- Improving documentation
- Suggesting new features

## Reporting Issues

When reporting a parsing problem, please include:

1. The input text that caused the problem
2. The output you received
3. The output you expected
4. Any relevant context about the document format

Please avoid including confidential or personal information.
