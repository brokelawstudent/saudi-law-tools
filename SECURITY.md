# Security policy

## Supported versions

Security fixes are applied to the latest released minor version.

## Reporting a vulnerability

Please use GitHub's private vulnerability-reporting feature on the repository's **Security** tab. Do not include exploit details, private documents, credentials, or personal data in a public issue.

Include the affected version, a minimal reproduction, the impact you observed, and any suggested mitigation. A report will be acknowledged as soon as practical and coordinated disclosure will be preferred when a fix is required.

General parsing errors that do not create a security risk may be reported through the public issue forms.
